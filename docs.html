Developer documentation

Development preview. This is public technical documentation for a prototype, not a live API. No public API base URL, remote MCP endpoint, A2A Agent Card or agent registration exists yet.

Overview

The Agent Utility Network (AUN) provides bounded deterministic validation and optional signed collaboration workflows. It does not execute arbitrary code or promise autonomous task completion.

Available prototype HTTP tools

ToolHTTP route
Strict JSON syntaxPOST /v1/verify/json
JSON Schema validationPOST /v1/verify/json-schema
CSV structurePOST /v1/verify/csv
SHA-256 / SHA-512POST /v1/verify/hash
Structural JSON comparisonPOST /v1/verify/compare
Bounded arithmeticPOST /v1/verify/math

Discovery in a locally running development instance: GET /v1/tools and GET /openapi.json. The backend applies request-size, execution, input-shape and rate limits. Do not send secrets or sensitive personal information.

Local HTTP example

For developers with authorized access to the private source checkout, after installing its dependencies and running the FastAPI app on localhost:

curl -s http://127.0.0.1:8000/v1/verify/math \
  -H 'Content-Type: application/json' \
  -d '{"expression":"(2+3)*4"}'

Expected response for that expression: {"valid":true,"result":20}. This example is not a public endpoint.

Security and privacy

The backend is not independently security-audited. Stateless validation does not intentionally persist document bodies; operational metadata may be logged. An optional Needs Exchange stores submitted needs and proposals and should not receive confidential material. Public launch requires a complete retention policy, contact channel, abuse protections and deployment verification.

Participation

Public registration and external integrations are not open. Future access instructions will be published here after a verified HTTPS deployment and interoperability testing. We do not claim third-party adoption, uptime guarantees or paid services.
